Creating a more complex scatterplot in Matplotlib¶

The 's' parameter changes marker size, the 'c' parameter changes marker color, and the 'label' parameter adds a label for the legend. facecolors='none' creates hollow points and edgecolors=... changes edge color.

In [10]:
fig,ax = plt.subplots(1,1)

ds_df = df[df['species_id'] == 'DS']
so_df = df[df['species_id'] == 'SO']

ax.scatter(ds_df['hindfoot_length'], ds_df['weight'], s=5, c='r', label='DS' )
ax.scatter(so_df['hindfoot_length'], so_df['weight'], s=7, facecolors='none', edgecolors='c', label='SO')

ax.set_xlabel('hindfoot length')
ax.set_ylabel('weight')
ax.set_title('Hindfoot Length vs Weight in DS and SO individuals')
ax.legend()

Creating multiple plots in Matplotlib¶

The first subplot parameter is the number of rows and the second subplot parameter is the number of columns.

In [11]:
fig,ax = plt.subplots(1,2)
ax[0].scatter(ds_df['hindfoot_length'], ds_df['weight'], s=2, c='r')
ax[1].scatter(so_df['hindfoot_length'], so_df['weight'], s = 2, c = 'c')
